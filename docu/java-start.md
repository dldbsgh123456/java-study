## JDK 구성
```
JRE - 실행 환경 => 라이브러리 포함
JVM (Devlopment Tool -> bin)
    javac - 컴퓨터가 인식하는 언어 변경 -> 컴파일
    java - 프로그램 실행 -> 화면 출력 (한 줄 씩 읽어서 출력(인터프리터)
    javap - 역컴파일러
    javaw - 서버구동 -> 톰캣(웹서버)
    jar : 배포 -> zip  but, 자바파일(x) -> .class 파일만 묶어줌
```

## Java 특징
```
- 모든 운영체제의 호환성이 좋다
- 객체 지향 프로그램 -> 조립해서 사용
```
## Java 규칙(개발자의 약속)
```
- 클래스명 : 첫 자 대문자 -> 단어가 두 개 이상 -> 첫 자만 (ex filename -> FileName), 한글 사용 가능 but, 영문사용 권장
- 변수명 : 소문자 시작
- 상수명 : 모든 알파벳을 대문자
- 메소드 : 소문자 시작
- 문법 : 들여쓰기 / 문장이 종료되면 ;(세미콜론) 사용
- 주석 : // -> 한 줄 주석 , /* */ 별 사이에 여러 줄 가능
```
## 데이터 저장
```
같은 데이터를 저장 : 배열  
다른 데이터를 저장 : 클래스
=> 메모리 저장 (RAM) -> 휘발성 -> 프로그램 종료 시 다 사라짐  
영구적 저장은 file but, 보안 취약,연결해서 사용이 어렵다
```
## 저장공간 (메모리)
```
MethodArea : 메모리 / 정적 데이터 저장 (static)
Stack : 변수저장 -> 메모리 자체 관리 {}를 벗어나면 자동 삭제
Heap : 개발자가 만든 -> 데이터형이 저장 
메모리 크기
1 bit - 0,1 둘 중 한 개  
8 bit(1 byte) - 0,1이 8개가 섞여 있음 , 8 bit == 1 byte  
부호비트 - 맨 앞이 0 이면 양수 , 1 이면 음수
