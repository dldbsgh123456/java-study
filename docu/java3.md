### 연산자

#### 부정 연산자
++ / --  -> byte,int,long,char
! -> boolean

#### 증감 연산자 (--도 같음)
++a(전치연산자) : 증가먼저 다음에 다른연산
a++(후치연산자) : 다른연산 다음에 증가
정수/문자만 가능
1증가/1감소

#### 형변환 연산자
   =========================> 자동 형변환(값 손실이 없어서): 메모리 크기가 커져서  
byte < char < int < long < double  
  <========================= 강제 형변환(값 손실이 있어서) : 메모리 크기가 작아져서  
boolean / String은 제외
          ------ 변환 가능(나중에 다시 봄)
